✓ SUBTASK 1: Extractive Strategy (Cosine Similarity)
  ├─ Sentence tokenization (NLTK punkt)
  ├─ TF-IDF vectorization (max_features=5000)
  ├─ Cosine similarity scoring
  └─ Top-3 hint extraction
  └─ Performance: 345 sentences/second

✓ SUBTASK 2: ML-Scored Strategy (Logistic Regression)
  ├─ 5 feature extraction:
  │  ├─ tfidf_similarity (question-sentence cosine)
  │  ├─ keyword_overlap (matching tokens)
  │  ├─ position (relative location)
  │  ├─ sentence_length (word count)
  │  └─ question_length (word count)
  ├─ Logistic Regression training
  ├─ Probabilistic hint scoring
  └─ Performance: 205 sentences/second

✓ SUBTASK 3: Evaluation Metrics
  ├─ Precision@3: 0.9760 (97.60%)
  ├─ Recall@3:    0.9760 (97.60%)
  └─ Accuracy:    0.9760 (97.60%)

✓ SUBTASK 4: Artifact Serialization
  ├─ Extractive generator → extractive_generator.pkl

  ├─ Dev results (x2) → *_dev_results.pkl
  ├─ Metrics → evaluation_metrics.pkl
  └─ All saved using joblib (6 files, 1.9 MB total)

   → Suggests either strategy could be production choice
   → Ensemble approach could improve further
